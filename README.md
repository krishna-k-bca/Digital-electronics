                   NUMBER SYSTEM 

number system is defined as system of writing for expressing numbers. it is the mathematical notation for representing numbers of a given set by using digit or other symbols in a consistent manner. 
  
               TYPES OF NUMBER SYSTEM 

some important types of number system are-
1. Binary number system(Base -2 , number 1 and 0)
2. decimal number system (Base- 10, number 0-9)
3. octal number system (Base- 8, number 0-7)
4. hexadecimal number system (Base- 16, number 0-15)
